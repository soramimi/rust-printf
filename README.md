# hoge

Rust で書いた、C の `printf` に似た書式化ライブラリ(実験用)。
メソッドチェーンで引数を渡し、`%d` や `%s` などの書式指定に従って文字列を組み立てます。

```rust
format("Copyright (C) %d %s. All rights reserved.\n")
    .d(2026)
    .s("S.Fuchita")
    .out();
// Copyright (C) 2026 S.Fuchita. All rights reserved.
```

## ビルドと実行

```sh
cargo run
```

`src/main.rs` の `main()` に、各機能の動作確認用の呼び出しが並んでいます。

## 使い方

`format()` でフォーマット文字列を渡し、書式指定と同じ順番で引数メソッドを呼びます。最後に出力メソッドで結果を取り出します。

```rust
format("[%05d][%-8s][%.2f]\n").d(42).s("abc").f(3.14159).out();
// [00042][abc     ][3.14]

let s = format("%s-%05d").s("id").d(42).str(); // "id-00042"
```

### 引数メソッド

| メソッド | 引数の型 | 主に対応する書式 |
|---|---|---|
| `s(v)` | `&str` | `%s` |
| `d(v)` | `i32` | `%d` `%u` `%o` `%x` `%X` |
| `ld(v)` | `i64` | `%ld` `%lu` `%lo` `%lx` `%lX` |
| `u(v)` | `u32` | `%u` `%o` `%x` `%X` |
| `lu(v)` | `u64` | `%lu` `%lo` `%lx` `%lX` |
| `f(v)` | `f64` | `%f` |
| `arg(Value)` | `Value` | 上記すべての土台 |

### 出力メソッド

| メソッド | 動作 |
|---|---|
| `out()` | 標準出力に書き出す |
| `err()` | 標準エラー出力に書き出す |
| `str() -> String` | 何も表示せず、組み立てた文字列を返す |

いずれも `Print` の状態を変更しないため、続けて何度でも呼べます。改行は自動では付かないので、必要なら書式文字列に `\n` を含めてください。

## 書式指定

```
%[フラグ][幅][.精度][l]変換文字
```

### 変換文字

| 指定 | 内容 |
|---|---|
| `%d` | 符号付き 10 進数 |
| `%u` | 符号なし 10 進数 |
| `%o` | 8 進数 |
| `%x` `%X` | 16 進数(小文字 / 大文字) |
| `%f` | 浮動小数点数(精度の既定値は 6) |
| `%s` | 文字列 |

### フラグ

| フラグ | 内容 |
|---|---|
| `-` | 左寄せ |
| `+` | 非負数にも `+` を付ける |
| (空白) | 非負数の前に空白を付ける |
| `0` | 零埋め(`-` と併用した場合は `-` が優先) |

### 長さ修飾子 `l`

`%u` `%o` `%x` `%X` に付けると、値を 64 ビットとして解釈します。付けない場合は 32 ビット(`u32`)です。

```rust
format("[%x][%lx]\n").ld(-1).ld(-1).out();
// [ffffffff][ffffffffffffffff]
```

### 意味を持たない指定の扱い

エラーにはならず、無意味な指定を無視して出力します。

- `+` と空白は、`%d` と `%f` に数値を渡した場合だけ有効です(符号なし変換では無視)。
- `0` は、数値変換に数値を渡した場合だけ有効です。`inf` と `nan` にも適用しません。
- 精度は `%f` に実数を渡した場合だけ有効です。`%s` でも切り詰めません。
- `l` は符号なし変換でだけ意味を持ちます。`%d` は常に値全体を出力します。
- 引数の型と変換文字が一致しない場合(`%s` に整数、`%d` に文字列など)は、値をそのまま文字列として出力します。この場合に有効なのは `-` と幅だけです。

## 未実装・制限事項

- `%%`、`%c`、`%p`、`%e`、`%g`、`#` フラグ、`*` による幅の指定には未対応です。
- 引数の過不足は検出しません。足りない書式指定はそのまま出力され、余った引数は無視されます。
- 変換文字が見つからない書式指定以降は、出力されません。
- 幅は文字数で数えます。全角文字の表示幅は考慮しません。
